I use layer architecture, monolith.

language: Typescript
Framework: Express
Environment: Node.js
Database: postgresql
Files: cloudflare r2
Cache: redis

Prerequisites:
Node.js
Docker
PostgreSQL

Getting started:
Clone the repo:

git clone https://github.com/knadarzynskitp-a11y/IncidentVault.git

Install Dependiences:
 cd backend
 npm i
